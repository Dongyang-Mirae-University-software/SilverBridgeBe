FCM 토큰 발급 / 푸시 수신 테스터

  1. 아래 script 안의 firebaseConfig와 vapidKey를 Firebase Console에서 받은 값으로 교체
  2. 같은 값을 firebase-messaging-sw.js 에도 동일하게 입력
  3. 로컬 HTTPS 또는 localhost 로 서빙 (서비스 워커 필수). 예: 이 폴더에서 npx http-server -p 8080
  4. 브라우저로 http://localhost:8080 접속 → 토큰 발급 → 백엔드 POST /api/notifications/fcm-token 에 등록

## 1. A. 흉기 유지 조건

- 흉기도 화재와 같은 구조로 **한 장짜리 양성으로는 알리지 않는다**(시간 기준 창, 최소 장면 수, 끊김 리셋, 세션당 1분 1회 보류 로그 `[KNIFE-HOLD-PENDING]`). 킬 스위치 `KNIFE_HOLD_ENABLED`(기본 true).
- 근거: 가정 영상 6.35시간에서 흉기 잘못 알림 5건. 칼을 2~3초 이상 드는 위협 장면은 짧은 유지 조건으로도 잡힌다.
- gosky 적용 값(`.env`, 백업 `.env.bak_20261016-1333-knife-hold`):

| 항목 | 값 |
|---|---|
| `KNIFE_HOLD_SEC` | 1.0 |
| `KNIFE_HOLD_RATIO` | 0.5 |
| `KNIFE_HOLD_MIN_SCENES` / `MAX_GAP_SEC` | 3 / 10 (코드 기본값) |
| `KNIFE_DANGER_THRESHOLD` | 0.4 (변경 없음) |
| 낙상 `FALL_DANGER_THRESHOLD` / `FALL_CONF_THRESHOLD` | 0.2 / 0.15 (변경 없음, 유지 확인) |

- 알림은 분석이 초당 약 10~12회일 때 약 1초 동안 절반 이상 양성이 이어져야 나간다(대략 0.5초 이상 늦어짐).
- 테스트: 전체 259 passed. 새 테스트 - 순간 양성 보류, 유지 시 알림, 킬 스위치, 화재 이력 분리, 종료 시 초기화, f32 판정 일치. 기존 4건은 "흉기는 한 장으로 danger"를 전제로 해 `knife_hold_enabled=False`로 조정, "흉기는 유지 조건 없음"을 고정하던 테스트는 새 동작 테스트로 교체.

## 2. B. 품질 검사 속도

### 2-1. 병목은 Laplacian이 아니라 디코드다 (로컬 합성 화면, 혼합 해상도 600장)

| 단계 | 시간 |
|---|---|
| 흑백 JPEG 디코드 | 약 2.3ms |
| resize + 흰색·검은색·밝기 + Laplacian | 약 0.56ms (Laplacian f64 약 0.5ms) |

- 이전 문서(2026-10-15 test-ai-live-decode-once 5절)의 "Laplacian이 대부분" 추정은 틀렸다.
- 판정이 바뀌지 않는 최적화로 줄일 수 있는 폭이 작다. 디코드를 근본적으로 줄이는 방법은 1회화(PR #17)인데 운영 영향으로 #18에서 되돌려진 상태라 이번에 다시 하지 않았다.

### 2-2. 시도한 안

| 안 | 결과 |
|---|---|
| 축소 디코드 `IMREAD_REDUCED_GRAYSCALE_2` | 약 10% 빠르지만 600장 중 5장(0.8%) 판정이 달라져 **폐기** |
| Laplacian CV_64F → CV_32F | 판정 flip 0건. **채택**(PR #19) |
| Laplacian CV_16S + meanStdDev | f32와 비슷, 채택 안 함 |

### 2-3. gosky 컨테이너 측정 (`nice 19`, 합성 화면 300장 x 5회, 운영 컨테이너 안 임시 실행)

| 방식 | 프레임당 평균 | 판정 불일치 |
|---|---|---|
| f64 (이전) | 1.157ms | - |
| f32 (현재) | 1.124ms | **0 / 300** |

- 감소 약 0.033ms (약 3%). 로컬 추정(0.15ms)보다 작다 - gosky CPU에서 디코드가 더 빠르고 Laplacian 비중이 작다. 반복 간 편차(1.08~1.25ms)와 같은 크기라 **효과는 있어도 측정으로 구별하기 어려운 수준**이다.
- 합성 화면은 모두 밝기 표준편차 30 미만이라 Laplacian이 매번 실행되는 조건이다(실제 방 화면도 어두운 곳이 많아 비슷할 것으로 추정, 미확인).

- 재시작 후 카메라 송출이 재등록 없이 자동 복구됐고(FE-1), 오류 로그 0건.

## 3. 남은 점

- 품질 검사 시간을 운영에서 계속 보려면 `[LIVE-INFER]`에 품질 항목을 따로 추가해야 한다(별도 작업, 재배포 시 송출 끊김).
- 품질 검사 비용의 대부분은 JPEG 디코드다. 줄이려면 1회화를 되돌린 사유를 확인한 뒤 다시 시도해야 한다.
- 흉기 유지 값(1.0초·0.5)은 실제 영상에서 흉기 알림 누락·지연이 없는지 지켜본 뒤 필요하면 `.env`(백업 후)로 조정한다.

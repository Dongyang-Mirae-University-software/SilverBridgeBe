# 약 표시 이름 - 용량·성분 괄호를 뗀 짧은 이름 (BE)

> 2026-11-19 요청, 2026-11-20 구현. 브랜치 `feature/medication-display-name`. 마이그레이션 없음.

## 왜

복약 화면(어르신 오늘 약·보호자 복약 관리·대시보드 "확인이 필요한 일")에 허가 품목명이 그대로 나왔다.
예: `다이아벡스정500밀리그램(메트포르민염산염)`. 어르신이 읽기 어렵고 줄이 넘친다.
저장된 이름(`medication.name`)은 허가 품목 대조·약사 확인용 원본이라 **바꾸지 않고**, 응답에 화면용 짧은 이름을 더한다.

## PHASE 0에서 확인한 것 (전제와 다른 점)

| 전제 | 실제 | 처리 |

| 알림 문구도 짧은 이름으로 | 복용 알림은 "약 드실 시간이에요." 고정(10-27부터 약 이름 없음), 미복용 요약은 개수만 | 바꿀 것 없음 |
| DTO 4종 | `MedicationItem` 하나를 오늘 약·보호자 목록·등록·일괄·수정·체크 응답이 함께 씀 | 1곳 |

## 사용자 결정 (2026-11-19)

1. 같은 약의 다른 용량이 함께 있어도 **늘 짧은 이름**(복용량·시각으로 구분).
2. 약 봉투 판독(OCR) 결과는 **원본 그대로** - 등록 전 확인 화면이라 용량까지 보여야 한다. OCR 응답은 바꾸지 않았다.
3. 직접 입력한 이름에도 **같은 규칙 + 안전장치**.

## 규칙 - `domain/medication/entity/MedicationDisplayName.of(name)` 한 곳

1. 끝쪽 괄호(`(…)`·`[…]`, 여러 개·중첩 포함)를 떼어 보고, **남은 앞부분이 용량이나 제형어(정·캡슐·캅셀·시럽·액·주·산·과립 등)로 끝날 때만** 뗀다.
   → `혈압약 (암로디핀 5mg)`·`아침약(혈압)`은 그대로(제형어 목록에 "약"이 없다).
2. 끝쪽 용량을 뗀다: 숫자 + 단위(밀리그램·밀리그람·마이크로그램·그램·밀리리터·mg·㎎·g·mL·μg·IU·단위·% 등, `/5mL`·`/밀리리터` 농도 포함).
   단위 없는 숫자는 앞이 제형어일 때만(`나소프라정500/20` → `나소프라정`, `비타민D3`은 그대로).
3. 이름 가운데 숫자는 떼지 않는다(`타세놀8시간이알서방정`, `인스콘600에프정`, `대우시메티딘300밀리그람정`은 끝이 용량이 아니라 그대로).
4. 결과가 비면 원본, `null`은 `null`.

| 입력 | 표시 이름 |
|---|---|
| 다이아벡스정500밀리그램(메트포르민염산염) | 다이아벡스정 |
| 시타민정50/1000밀리그램(시타글립틴인산염, 메트포르민염산염) | 시타민정 |
| 뉴로메틴캅셀500마이크로그람(메코발라민)(수출명:필발라민캡슐)(수출용) | 뉴로메틴캅셀 |
| 일성클래리트로마이신건조시럽125mg/5mL | 일성클래리트로마이신건조시럽 |
| 휴온스아미노주3% | 휴온스아미노주 |
| 타이레놀 500mg (직접 입력) | 타이레놀 |
| 혈압약 (암로디핀 5mg) (직접 입력) | 그대로 |

전체 표는 `MedicationDisplayNameTest`(40건).

## FE 계약 (추가만, 기존 필드 유지)

| 위치 | 새 필드 | 기존 필드 |
|---|---|---|
| `MedicationItem` - `GET /api/ward/medication/today`의 `medications[]`, `GET /api/guardian/medication`의 `data[].medications[]`(피보호자별 `WardMedicationSummary`), 등록·일괄·수정·체크 응답 | `displayName` | `name`(원본) |
| 대시보드 `GET /api/guardian/dashboard`의 `medication.mostUrgent` | `displayName` | `name` |
| WS `medication-taken` 페이로드 | `medicationDisplayName` | `medicationName` |

- 화면 표시는 `displayName`, 수정 창의 입력 기본값은 `name`(원본)을 쓴다 - 수정 창에 짧은 이름을 넣고 저장하면 원본이 사라진다.
- OCR 응답(`MedicationOcrResponse`)은 바뀌지 않았다.
- **FE 반영 (2026-11-20, FE #294 `c944d7c`, gosky FE dev 실측)**: 어르신 오늘 먹을 약·보호자 복약 카드가 `displayName`(없으면 `name`)을 표시하고 원본은 `title`, 수정 창 입력값은 원본, OCR 확인 화면 무변경. FE 자체 축약(`wardMedicationDisplayName(s)`)은 지웠다 - 줄이는 규칙은 BE 한 곳. 점검 `(2026-11-20) audit-fe-294-medication-display-name.md`(PASS).

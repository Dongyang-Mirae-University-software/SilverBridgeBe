# 피보호자 문자·푸시 단순화 - 약 이름·시각 빼고 한 줄로 (2026-10-27)

> branch `fix/ward-sms-plain` · 마이그레이션 없음 · 발송 정책·채널·쿨다운 무변경

## 배경

2026-10-27 피보호자 휴대폰에 온 실제 문자가 어르신이 읽기에 어려웠다.

- 복약: `[복약 시간이에요] 저녁 약 6개 드실 시간입니다(19:00). 허가 품목명 1정, … 반 알 외 4개` - 113바이트라 장문(LMS)이 됐고, 제목과 본문이 거의 같은 말을 되풀이했다.
- 화재(본인): `[화재 감지] 주방에서 화재가 감지되었습니다. 안전한 곳으로 대피해 주세요.` - 해야 할 행동이 맨 뒤에 있다.

원인: 문자 채널(`SmsNotificationChannel`)은 Solapi에 제목(subject) 없이 `[제목] 본문` 한 줄을 보낸다. 90바이트를 넘으면 발송사가 LMS로 자동 전환한다.

## 규칙 (피보호자가 받는 알림만)

1. 제목은 앱 이름 `실버브릿지` 하나라서 문자는 `[실버브릿지] 본문` 한 줄이 된다. 본문에 제목을 다시 넣지 않는다.
2. 약 이름·개수·용량·숫자 시각·괄호를 넣지 않는다. 한 문자에 행동 하나만 담는다.
3. 문자 한 줄이 **EUC-KR 90바이트 이하**(단문)여야 한다. EUC-KR에 없는 글자는 2바이트로 센다(`WardNotificationText`).
4. 단정 금지 원칙은 그대로다. 화재·흉기·낙상은 "감지"로 말하고, 복약 재알림은 "안 드셨다"고 하지 않는다.
5. **푸시도 같은 제목·본문을 쓴다**(사용자 결정). 앱 화면(WS) 제목은 종류가 보이게 그대로 둔다(예: "화재 감지"·"보호자 연결"·"연결 해제").
6. 보호자 문구, 알림톡, 이메일은 바꾸지 않았다. 알림 이력에는 새 문구가 그대로 남는다.

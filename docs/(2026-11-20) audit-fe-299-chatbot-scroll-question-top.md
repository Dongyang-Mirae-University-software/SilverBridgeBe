## 변경 요약

어르신(`/ward/chatbot`)·보호자(`/guardian/chatbot`) 챗봇은 답이 오면 늘 맨 아래로 스크롤해, 응급·자해 안내나 긴 상담 답이면 방금 한 질문이 위로 밀려 보이지 않았다.

- `ChatbotContent.tsx`: 새 AI 답이 붙었을 때 질문+답이 대화창보다 길면 직전 질문 말풍선 윗부분(12px 여백)을 대화창 맨 위에 맞춘다. 짧으면 지금처럼 맨 아래. 마지막 메시지 id가 바뀔 때만 판단한다.
- `ChatBubble.tsx`: 질문 말풍선에 `data-message-id`만 추가(디자인·문구 변경 없음).
- 브라우저 테스트 13건: 두 화면 x 태블릿 1180x820·아이폰 393x852 x 응급·자해·일반 상담 + 짧은 답. 수정 전 코드로 돌리면 긴 답 12건이 실패한다.

## 안전성

- `querySelector`에 넣는 id는 `CSS.escape`로 감싼다. 목록·질문 요소가 없으면 맨 아래로 내리는 기존 동작으로 돌아간다.
- `data-message-id` 값: 대화 화면은 무작위 id, 지난 대화 보기는 서버 기록 번호 + `-q`(이미 API 응답에 있는 값). 사용자 식별자·내용 없음.
- lint(react-hooks 포함) 0, tsc 0.
